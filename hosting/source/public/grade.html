Before sending

This optional action sends your task IDs, edited source, and custom regression cases through this site to the Hugging Face grading service. Your written diagnosis, random participant code, timestamps, and session ID are removed from the request. Do not include secrets in source or cases.

The service runs each case in a fresh, restricted JavaScript VM. It has no JavaScript filesystem, network, Node APIs or Python callbacks. It is a different engine from the frozen Docker grader used by the local study protocol.

Feedback covers executable behaviour and regression quality only. Human diagnosis remains unscored. It does not certify employability, identity or unaided work. Reports are marked development data and excluded from the learning-study pipeline.

The app has no submission database. Hosting providers and Gradio handle requests and temporary queues under their own policies. Keep the downloaded report if you want a copy. No email or automatic sharing is performed.
